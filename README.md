# 💰 NexSpend AI

### AI-Powered Personal Finance & Expense Tracking App

NexSpend AI is a modern Android application designed to help users track their income, expenses, budgets, savings goals and personal financial activity in one place.

The project was developed with a focus on creating a practical, user-friendly and intelligent personal finance experience.
